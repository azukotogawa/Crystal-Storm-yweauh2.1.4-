# Fonts

## Pixelify Sans

- File: `PixelifySans.ttf` (variable weight).
- Copyright 2021 The Pixelify Sans Project Authors (https://github.com/eifetx/Pixelify-Sans).
- License: SIL Open Font License, Version 1.1. The full text is `OFL.txt` in this folder.
- License FAQ: https://scripts.sil.org/OFL

The UI theme (`ui/theme/theme_builder.gd`) loads this file and draws it as a `FontVariation` at OpenType weight 520. UI scale does not change the font file; it uses `Window.content_scale_factor`.

The frontend main menu credits the font on the `FontCredit` label.
