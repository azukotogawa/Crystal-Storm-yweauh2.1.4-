# Crystalstorm - Godot 4 Project Rules

## Godot 4 / GDScript Coding Rules
- You are writing code exclusively for Godot 4.
- Always use the new Godot 4 signal syntax: `button.pressed.connect(_on_button_pressed)` instead of the old `.connect("pressed", self, "_on_button_pressed")`.
- Use `CharacterBody3D` (or `CharacterBody2D` for legacy 2D) instead of `KinematicBody`. Use `move_and_slide()` without passing linear velocity vectors as parameters when using the built-in physics body.
- Use `@onready` instead of `onready`.
- Use `@export` instead of `export`.

## Project Overview
**Crystalstorm** is a maze-builder tower-defense hybrid. The player constructs elaborate terrain mazes (build walls, dig tunnels) to maximize time before a growing crystal entity overwhelms the map. The crystal absorbs plants, animals, and ruins to gain power and spawn enemies. The player must balance maze-building/exploration with direct combat using weapons/relics. Win by killing the Origin Warden (immediate victory) or by destroying every crystal spawn point. The origin heart stays sealed while any minor spawn remains and while the warden lives.

Core gameplay pillars:
- Long "Maze phase" (strategy, building, routing).
- Short "Combat phase" (action).
- Topographical freedom, verticality via digging, time pressure from crystal growth.

## Current Architecture & State (2026-07)
- Full 3D voxel engine (2D prototype archived under `archive/legacy/`).
- Chunked infinite world:
  - `ChunkData.SIZE = 16`, `HEIGHT = 160`.
  - Threaded generation in `ChunkManager` (worker thread + semaphore/mutex).
  - Greedy meshing per face direction (top, bottom, sides) producing quads for `MultiMeshInstance3D`.
  - Custom spatial shader (`shaders/ChunkView.gdshader`) + texture atlas (7x10 grid) for voxel texturing + simple face-based shading.
- **World state authority:** `world/world_state.gd` (`WorldState`) owns all persistent mutable overlays (terrain height/build, feature cells/tile overrides/towns/spawns, channels) with monotonic domain revisions, batch transactions, change signals, session replace/reset, snapshot export/import (rollback), and save overlay apply/export. `TerrainEdits` / `FeatureRegistry` / `ChannelRegistry` are compatibility façades that delegate to the active session — do not reintroduce process-global static overlay maps. Worker mesh jobs freeze mesh-input overlays via `ChunkData.capture_worker_snapshot()` (stamped with `mesh_input_revision`); `ChunkManager.is_mesh_job_stale` rejects superseded tokens or mesh stamps.
- **Chunk pipeline stages:** `chunks/chunk_pipeline.gd` defines stream_request → snapshot → column → mesh → buffer → apply. Worker entry is `ChunkPipeline.run_worker_job` (stateless w.r.t. manager scratch): greedy visit grids are job-local (`alloc_greedy_visited`); micro skip lives on the job's `ChunkData._mesh_job_micro_skip`. `ChunkManager` remains the lifecycle façade (tokens, streaming, upload).
- **Deferred world bake:** Cold/invalid index primes the start stream ring + origin 3×3 via `WorldBakeService._bake_one_chunk`. `INITIAL_STREAM_READY` waits until `ChunkManager.is_start_region_ready()` (player stream ring resident + start packages). Loading UI shows live `start_region_status()` occupancy, not a canned percent. `GameplayInput.world_loading` blocks actions until the overlay dismisses. Remaining packages fill on a bounded `WorkerThreadPool` queue (`WorldBakeWorkerJob`; stream > nearby > fill). Main thread only schedules, collects, registers packages, and commits `world.index` when every expected `.chk` exists. `valid` only then. Far travel waits one on-demand worker job (same package bytes). Fill never calls `WorldState.replace_active` or mutates live overlays. Rollback: `CRYSTALSTORM_BAKE_DEFER_FILL=0` awaits the full bake before stream. `CRYSTALSTORM_BAKE_FILL_SYNC=1` restores main-thread 1/frame fill.
- **Macro / micro terrain:** Generation + column maps use dense `MacroLayerGrid` (surface/tile/flags). Dig/build/cliffs allocate sparse `MicroLayerGrid` bricks; mesh stage skips micro columns in greedy then emits via `MicroTerrainMeshCompositor` (render hides distinction). Micro is **not** persisted — save stores `height_delta`/`build_tile` only; `derive_micro_from_terrain_edits` on generate/rebuild restores bricks. Env: `CRYSTALSTORM_MACRO_TERRAIN`, `CRYSTALSTORM_MICRO_TERRAIN` (default on).
- **Water:** `VoxelFluidService` is edit-driven: sleep when `_dirty_cells` is empty; never scan `all_fluid_positions` on the tick path. `mark_region_dirty` / `recompute_region_now` (dig/channel) gather only the dirty box + neighbors. River *tiles* stay visual; inject 0.95 only on cells that already have a player channel. Walking does not wake the sim. `get_sim_diagnostics().phase_us` splits gather/copy/sim/persist/visual. Crystal conductivity still reads `ChannelRegistry`.
- **Building:** `BuildingRegistry` builtins: `stone_wall`/`wood_wall` (stack height), `gate` (passage, no height, crystal baffle), `bridge` (raise over digs). Place via `TerrainEditor.try_build*` — delay `get_build_delay()` ~0.03s. Demolish via `TerrainEditor.try_remove` (one wall layer per call; refunds 1 material; refuses towns/ruins). Input: **LMB subtract** (pick digs or removes; materials remove), **RMB place** (wall / Shift gate / Ctrl bridge). WASD move, Space jump, Q/E yaw. Feedback: `structure_built` → highlight pulse + place flash. Authored meshes instance `scenes/world_object.tscn` (`WorldObject`) — gameplay cell + stored `yaw` + `visual_id` → mesh + debug Area3D. Visual identity is `visual_id`/`build_id`/flags only (never infer wall/bridge from DIRT tile). Voxels stay MultiMesh.
- **Ramps:** One landing column. Wedge mesh AABB = one voxel; approach keeps its greedy top. Collision `walkable_height_from_entry` slopes only the landing. Corner/concave transforms are right-handed yaw (no negative-scale basis). Incremental remesh halo is 1 cell (`REBUILD_EDGE_BAND`/`MESH_MARGIN`).
- **Representation contract:** `helpers/world_visual_coords.gd` is column↔world (XZ = column × voxel_scale). Face codes: 0 top, 3–6 sides (Y-greedy is top only). Incremental remesh **clips** greedy slabs outside `patch_rect` (do not drop whole merged quads). Structure yaw lives on FeatureRegistry. Audit: `LIVE_WORLD_ARCHITECTURE_AUDIT.md`. Live validation: `LIVE_GAMEPLAY_VALIDATION.md`.
- **Dev keys:** F3 compact debug overlay, F4 Live World Inspector (discrepancy flags), F11 bug report, ESC pause (Resume / Settings / World Select / Quit). Terrain collision stays `VoxelFloorProbe`; `WorldObject` Area3D is debug-only.
- **Terrain loop (complete):** Cursor = live mouse cell (no hysteresis). Dig/build **only** that cell (`get_action_column`); out-of-range fails with toast (no facing dig). Edits flush mesh + immediate water reflow; `terrain_edited` invalidates crystal height caches. Macro/micro dirty path on dig. Soft-follow movement; world borders stop player/crystal. Visual: dig dust + build flash + highlight pulse.
- **World borders:** `helpers/world_border.gd` — playable half 1024; ±X ocean, ±Z mountain. Player: `blocks_player_at` (ocean tiles always; border mountain tiles + early transition bands). Crystal: `allows_crystal` / `is_playable` in sim active mask. Map: rim styling in `TopographicalMapBuilder._apply_border_map_style`.
- **Save architecture (schema v2):** `systems/save_schema.gd` + transactional `SaveGameService`. WorldState is the sole overlay persistence authority (`export_persistence_bundle` / `import_persistence_bundle` with revisions). Per-world file `user://saves/world_{id}.json` (`save_world_id` / `load_world_id`); `WorldManager.active_world_id` + `pending_resume` so catalog Play restores after `INITIAL_STREAM_READY`. Leave World saves first, then clears ids. Slot files remain for F5/F9. Load: validate/migrate → checkpoint → pause stream/sim → apply WorldState → runtime → single rebuild → resume; failure rolls back checkpoint. Do not re-scatter overlay serialization into static registries. Micro bricks are never in the payload. Crystal mite unlock is `AbsorptionUnlockDef.unlock_at_start` on the GameConfig table (no CrystalManager special-case).
- **Composition root:** `systems/composition_root.gd` + `service_registry.gd` + `runtime_config_resolver.gd` own production boot stages (CONFIGURED → … → RUNNING), typed service registration, and EffectiveRuntimePolicy precedence (defaults → project → quality → platform → debug). Critical handoffs use `ConfigService.apply_to_registered` / `PerformanceService.apply_to_registered` (policy folded into effective quality via `fold_policy_into_quality`); groups remain UI/debug adapters only. Quality must not mutate authored `WorldGenConfig` authority fields. Diagnostics: `CompositionRoot.get_diagnostics()` / `get_health_report()`.
- **Spatial Query Layer:** `systems/spatial_query_layer.gd` + `spatial_query_service.gd` own runtime spatial **discovery** (grid + chunk indices; radius/AABB/nearest/ray/region/neighborhood). Combat/targeting obtain candidates through the layer; no gameplay logic inside the layer. Chunk load/unload and entity move update indices incrementally; save restore calls `rebuild_from_runtime()`.
- **Crystal simulation split:** `CrystalManager` is the gameplay façade. `CrystalSimulation` (pure, no scene tree) consumes `CrystalSimSnapshot` and emits typed events; `CrystalPresentation` schedules mesh rebuilds from those events. Do not re-merge fluid/mesh logic into the façade or add `get_tree()` inside `CrystalSimulation`.
- World gen: `world/InfiniteNoiseWorld.gd` using FastNoiseLite (height/precip + dedicated river_path for networks) → exactly 5 real-life biomes (plains, steppe, forest, marsh, mountain) with topo/rugged + river moisture bias; realistic rivers that carve depth (incised channels at lowered surface_y using RIVER + depth variants) so they traverse biomes following valleys (see helpers/voxel_types.gd).
- Player movement: Custom voxel-aware collision + gravity (not yet relying on CharacterBody3D physics body features in the script). Orthographic isometric Camera3D with 90° rotation steps and mouse wheel zoom.
- Scenes: `scenes/frontend.tscn` is the player-facing entry (MAIN MENU → WORLD SELECT → NEW WORLD / SETTINGS). Play loads `scenes/main.tscn` (Node3D root "Game", script `main.gd`) and is playable at `INITIAL_STREAM_READY`. Leave World returns to WORLD SELECT. Catalog: `systems/world_manager.gd` (no UI `.chk` IO). Dev biome viewer: `scenes/world_viewer.tscn`. Legacy scenes live in `archive/legacy/`.
- Boot chain: `ConfigService` → `PerformanceService` → `GameVisualRegistry` → `WorldFeatures` (feature seed) → `VoxelWorld` creates `ChunkManager` → `on_chunk_manager_ready` binds TerrainEditor/EntityManager/config → `CrystalManager` sim → `WorldVisuals` refresh on `visuals_ready`.
- Living World content (Phase 1): `LivingWorldDirector` under `WorldFeatures` — biome HUD, ruin discovery (feeds crystal power), town militia toasts. Towns/ruins/wildlife seeded via FeatureRegistry; villagers + standing militia at bootstrap.
- Visual layers (`WorldVisuals` node): `Entities`, `Vegetation`, `Buildings`, `SpawnMarkers`, `CombatVFX` (with `CombatVisualFeedback`), `FeatureVisualLayer` (populator script).
- Important directories:
  - `chunks/` — core voxel runtime (ChunkManager, ChunkData, ChunkView).
  - `player/` — Player + Camera3D + voxel floor probe.
  - `world/` — WorldState, InfiniteNoiseWorld, features, terrain editor, feature visuals.
  - `systems/` — Config, performance, visuals registry, combat VFX, save.
  - `crystal/`, `entities/`, `helpers/`, `shaders/`, `config/`, `ui/`, `scenes/`, `scripts/` (headless verify suite).
  - `archive/legacy/` — retired prototypes (do not reference from production scenes).

## Development Guidelines
- Prefer the 3D voxel system in `chunks/` + `player/` for all new gameplay features (maze building, digging, crystal simulation, combat).
- When editing terrain interaction, go through `ChunkData` + `ChunkManager` APIs (get/set voxels, rebuilds, collision queries). Mutate persistent overlays via `TerrainEdits`/`FeatureRegistry`/`ChannelRegistry` façades or `WorldState` directly — never add new static overlay storage.
- Keep the world deterministic given a seed. Overlay restore uses `WorldState.restore_overlay_snapshot` / save apply for identical seed+payload replay.
- Thread-safety: generation jobs run off-main on frozen worker snapshots; use `call_deferred` for tree modifications. Do not read live WorldState maps from workers.
- Performance: 2D heightfield (surface+tile maps only) + Y-greedy rect merge + side run-length lips; BOTTOM faces disabled; RENDER_DISTANCE default=3; throttled render drain (5/chunk max per frame); debug UI rate-limited. Be mindful of total MultiMesh instances and streaming distance. Tune RENDER_DISTANCE in inspector for FPS vs horizon (higher = more draw).
- **Runtime profiler (permanent):** autoload `PerfProfiler` (`systems/perf_profiler.gd`). Hierarchical frame report (chunks/streaming/crystal/entities/world/render/ui/memory/workers + HOTTEST). Instrument with `begin`/`end`/`record_us`/`set_gauge` only — no gameplay changes. Debug panel `--- PERF ---` block; headless `scripts/profile_gameplay.gd`. See `PERFORMANCE_RUNTIME.md`. Budget target 16.6 ms/frame.
- **Frame budget scheduler (Phase 3):** autoload `FrameBudgetScheduler` — per-system unit + soft wall budgets, FIFO queues, min-units starvation prevention. Crystal event dispatch, living-world ruin scan, town defense ticks, and chunk apply drain through it. Critical crystal events still immediate; save export flushes dispatch. See `PERFORMANCE_PHASE3_REPORT.md`.
- **Juice / audio hooks:** autoload `AudioManager` (`systems/audio_manager.gd`) with Master/Music/SFX/UI buses. Ids live in `config/audio_manifest.gd`. Missing files are skipped. Particles and swing arcs are pooled in `VfxPool`. Hit-stop, shake, flash, and walk bob are `Juice`, gated by `PlayerSettings` (`screen_shake_enabled`, `hit_stop_enabled`, `flash_effects_enabled`, `reduce_motion`, bus volumes). Menus, keybinds, UI scale, the colour-blind palette, the tutorial, and the run summary are in `studio/wiki/UI.md`. See also `studio/wiki/Effects.md`. Do not add audio files until they are real recordings.
- Input: Current actions use built-in "ui_*" + custom "jump", "rotate_left", "rotate_right" (see `project.godot`).
- Testing the game: `godot scenes/main.tscn` or `godot .` (main scene set in project.godot). Headless CI: `godot --headless -s scripts/run_all_verify.gd` (full suite via `scripts/run_all_verify.sh`; includes `verify_world_state` + `verify_world_state_stale_worker`).
- Perf presets: env `CRYSTALSTORM_PERF_PRESET=low|medium|high|safe` or `CRYSTALSTORM_SAFE_MODE=1`.
